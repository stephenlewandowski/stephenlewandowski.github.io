01 · Overview

A bounded model-derived comparison.

The initial product uses area-weighted regional summaries for North Korea, South Korea, and the combined Korean Peninsula. It compares early (1975–1984), middle (1995–2004), and recent (2015–2024) periods and retains cell-year extracts, monthly profiles, missingness diagnostics, and static maps.

The selected 370 cells include 215 North Korea cells and 155 South Korea cells. In the current v2.0 extraction, no missing or undefined suitability values were encountered in the selected target cells for the three comparison decades. North Korea interpretation remains modeled extrapolation where direct observations are unavailable.

03 · Methods and code

Reproducible from source archive to static figure.

  • analyze_korea.py — extracts monthly rasters, applies the country mask, aggregates results, and renders static maps.
  • analyze_korea_japan.py — keeps the Korea scope explicit and maintains Japan as a separate comparator.
  • validate_outputs.py — checks row counts, ranges, missingness, cell counts, and expected map outputs.
  • Methods and protocol reports — document aggregation, uncertainty, population exposure, surveillance, drivers, and early-warning gates.

04 · Next sequence

Add evidence only when the input contract is met.

  1. Complete the Korea-only LandScan population-exposure join and alignment checks.
  2. Add ROK Aedes observations as a separate validation input with spatial and temporal holdouts.
  3. Describe heat, humidity, land-use, and population drivers while retaining correlated-predictor diagnostics.
  4. Evaluate any early-warning use only with out-of-sample performance, calibration, uncertainty, and an explicitly non-operational threshold.

Japan is maintained as a separate comparator, and Anopheles/malaria surveillance is a separate feasibility project rather than validation of this Aedes product.

Interpretation boundary

This is a regional model comparison, not an installation-level or operational early-warning product. Changes in suitability do not by themselves establish vector presence, disease incidence, transmission, or individual risk.
