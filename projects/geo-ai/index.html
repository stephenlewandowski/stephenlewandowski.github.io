How “geo” is GeoAI?

A planned evidence observatory for examining the spatial explicitness, data, methods, tasks, and evaluation practices of GeoAI and geospatial foundation-model research.

Status: Project outline in development · public code and results not yet released

01 · Overview

Make the spatial claim inspectable.

GeoAI and geospatial foundation-model work often uses geographic data, but “geospatial” can describe very different relationships among location, scale, geometry, spatial dependence, transfer, and decision context. The project will turn that distinction into an evidence-centered coding and comparison problem.

The starting point is the systematic review Measuring the spatial explicitness of GeoAI and geospatial foundation models, which screened 5,694 papers and analyzed 1,122 studies across topics, data types, AI methods, task categories, and methodological innovations.

02 · Project outline

Four work packages.

  1. Evidence matrix. Record study, task, data, geographic object, spatial relation, scale, and evaluation information with source-level provenance.
  2. Spatial-explicitness taxonomy. Distinguish geographic labeling from true spatial structure, spatial dependence, geospatial transfer, and decision-relevant spatial reasoning.
  3. Reproducible synthesis. Produce transparent counts, cross-tabs, uncertainty notes, and reviewable coding decisions rather than a single maturity score.
  4. Exploratory observatory. Add a small interactive or static explorer only if it makes a defensible comparison easier to understand than the evidence table alone.

The project will retain a static table and methods note as the fallback. It will not treat model branding, benchmark popularity, or geographic nouns in an abstract as evidence of spatial explicitness.

04 · Questions to test

What should count as spatial?

  • Does the method use explicit geometry, spatial topology, distance, neighborhood structure, or spatial dependence?
  • Is geographic context part of the prediction or merely a label attached after modeling?
  • What spatial scale, transfer problem, or geographic shift is evaluated?
  • Can a reader distinguish benchmark performance from evidence of spatial generalization?
  • Which claims are documented in the paper, which are coded judgments, and which are synthesis?

Current boundary

This page is an outline and research handoff, not a completed review database, benchmark, or claim that one field-wide spatial-explicitness score is valid. The next release should begin with a bounded coding protocol and a small, human-reviewed sample.
